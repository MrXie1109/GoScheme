# (srfi 133) — the vector library

The complete SRFI-133 API on top of R7RS's vectors, implemented in Go.  Where
R7RS or `(goscheme fast)` already define a name with the same meaning, this
library exports **that same binding** rather than a copy — a later `import`
shadows an earlier one, so one implementation for one name is what keeps the
libraries from disagreeing.

```scheme
(import (scheme base) (srfi 133))
```

## Constructors

| Procedure | Arguments | Description |
|---|---|---|
| `make-vector` | `(make-vector length [fill])` | R7RS's; exported from here as well. |
| `vector` | `(vector element ...)` | R7RS's. |
| `vector-unfold` | `(vector-unfold proc length seed ...)` | Calls `proc` with the index and the seeds and expects the element followed by the next seeds back — through `values` when there are seeds, as a plain value when there are none.  Fills from index 0 up. |
| `vector-unfold-right` | `(vector-unfold-right proc length seed ...)` | The same, filling from the end backwards. |
| `vector-copy` | `(vector-copy vector [start [end]])` | R7RS's, with the optional range. |
| `vector-reverse-copy` | `(vector-reverse-copy vector [start [end]])` | A new vector with the range reversed. |
| `vector-append` | `(vector-append vector ...)` | R7RS's. |
| `vector-concatenate` | `(vector-concatenate list-of-vectors)` | One vector holding all of them. |
| `vector-append-subvectors` | `(vector-append-subvectors vector start end ...)` | Concatenates the given half-open ranges. |

## Predicates

| Procedure | Arguments | Description |
|---|---|---|
| `vector?` | `(vector? object)` | R7RS's. |
| `vector-empty?` | `(vector-empty? vector)` | `#t` for a zero-length vector. |
| `vector=` | `(vector= elt= vector ...)` | `#t` when all the vectors have the same length and are element-wise `elt=`; different lengths are `#f`. |

## Selectors

| Procedure | Arguments | Description |
|---|---|---|
| `vector-ref` | `(vector-ref vector index)` | R7RS's. |
| `vector-length` | `(vector-length vector)` | R7RS's. |
| `subvector` | `(subvector vector start end)` | A new vector holding that half-open range; a range out of bounds is an error. |
| `reverse-list->vector` | `(reverse-list->vector list)` | `(list->vector (reverse list))` in one pass. |
| `vector->list` | `(vector->list vector [start [end]])` | R7RS's. |
| `list->vector` | `(list->vector list)` | R7RS's. |
| `vector->string` | `(vector->string vector [start [end]])` | R7RS's. |
| `string->vector` | `(string->vector string [start [end]])` | R7RS's; a vector of characters, not of byte values. |

## Iteration

| Procedure | Arguments | Description |
|---|---|---|
| `vector-fold` | `(vector-fold kons knil vector ...)` | Folds from the left calling `(kons state e1 e2 ...)` — the **state first**, the opposite of SRFI-1's list `fold`. |
| `vector-fold-right` | `(vector-fold-right kons knil vector ...)` | Folds from the right calling `(kons e1 e2 ... state)` — the state last. |
| `vector-map` | `(vector-map proc vector ...)` | R7RS's: a new vector of the results. |
| `vector-map!` | `(vector-map! proc vector1 vector ...)` | Stores `(proc e1 e2 ...)` back into the first vector and returns it; the vectors must have the same length. |
| `vector-for-each` | `(vector-for-each proc vector ...)` | R7RS's. |
| `vector-count` | `(vector-count pred vector ...)` | How many positions pass; the predicate gets the elements of a position in one call. |

## Searching

| Procedure | Arguments | Description |
|---|---|---|
| `vector-index` | `(vector-index pred vector ...)` | The first index where the predicate passes, or `#f`. |
| `vector-index-right` | `(vector-index-right pred vector ...)` | The last such index, or `#f`. |
| `vector-skip` | `(vector-skip pred vector ...)` | The first index where it **fails**, or `#f`. |
| `vector-skip-right` | `(vector-skip-right pred vector ...)` | The last index where it fails, or `#f`. |
| `vector-any` | `(vector-any pred vector ...)` | The first true value the predicate returns, or `#f`. |
| `vector-every` | `(vector-every pred vector ...)` | The last value it returns when every position passes, or `#f`; `#t` for empty vectors. |
| `vector-binary-search` | `(vector-binary-search vector key [comparison])` | The index of the first element equal to `key` in a sorted vector, or `#f`.  The comparison may be a `less?`-style predicate (what `(goscheme fast)` has always taken) or SRFI-133's three-valued procedure returning `-1`, `0` or `1`; the first call decides which. |
| `vector-partition` | `(vector-partition pred vector)` | Returns two values: a new vector holding the accepted elements followed by the rejected ones, and how many were accepted.  This is the binding `(goscheme fast)` exports too. |

## Mutators

| Procedure | Arguments | Description |
|---|---|---|
| `vector-copy!` | `(vector-copy! to at from [start [end]])` | R7RS's. |
| `vector-fill!` | `(vector-fill! vector fill [start [end]])` | R7RS's, with the optional range. |
| `vector-swap!` | `(vector-swap! vector i j)` | Exchanges two elements; an index out of range is an error.  Shared with `(goscheme fast)`. |
| `vector-reverse!` | `(vector-reverse! vector [start [end]])` | Reverses in place and returns the vector; the optional range is what SRFI-133 adds to the fast library's version. |

## Notes

* **Shared bindings.**  Fifteen names come from R7RS (`vector`,
  `make-vector`, `vector?`, `vector-length`, `vector-ref`, `vector-copy`,
  `vector-copy!`, `vector-append`, `vector-fill!`, `vector-map`,
  `vector-for-each`, `vector->list`, `list->vector`, `vector->string`,
  `string->vector`) and four from `(goscheme fast)` (`vector-swap!`,
  `vector-reverse!`, `vector-binary-search`, `vector-partition`).  Importing
  `(scheme base)`, `(srfi 133)` and `(goscheme fast)` together is safe.
* **Equal lengths.**  The folds, maps, `vector-count` and the index procedures
  require all their vectors to have the same length and raise otherwise;
  `vector=` answers `#f`.
* **`vector-map!` writes into its first vector**, which is the one difference
  in shape from R7RS's `vector-map`.
* The reverse procedures return the vector they wrote into, which SRFI-133
  leaves unspecified.

## Example

```scheme
(import (scheme base) (scheme write) (srfi 133))

(vector-unfold (lambda (i) (* i i)) 4)        ; => #(0 1 4 9)
(vector-unfold (lambda (i x) (values x (+ x 1))) 4 0)   ; => #(0 1 2 3)
(vector-fold (lambda (state x) (+ state x)) 0 #(1 2 3)) ; => 6
(vector-fold-right (lambda (x state) (cons x state)) '() #(1 2 3))
                                              ; => (1 2 3)
(subvector #(1 2 3 4) 1 3)                    ; => #(2 3)
(vector-count even? #(1 2 3 4))               ; => 2
(vector-index even? #(1 2 3 4))               ; => 1
(vector-skip even? #(2 4 5 6))                ; => 2
(vector-append-subvectors #(1 2 3) 0 2 #(9 8) 1 2)   ; => #(1 2 8)
(call-with-values (lambda () (vector-partition even? #(1 2 3 4)))
  (lambda (v kept) (list v kept)))            ; => (#(2 4 1 3) 2)
(vector-binary-search #(1 3 5 7) 5
  (lambda (a b) (cond ((< a b) -1) ((> a b) 1) (else 0))))   ; => 2
```
