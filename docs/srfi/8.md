# (srfi 8) — `receive`

Binding several values without spelling out `call-with-values`: the formals are
bound to the values the expression produces, and the body runs with them.  It
is written in Scheme and embedded in the binary, so it survives `goscheme
build`.

```scheme
(import (scheme base) (srfi 8))
```

## Syntax

| Form | Arguments | Description |
|---|---|---|
| `receive` | `(receive formals expression body ...)` | Evaluates `expression`, binds the values it returns to `formals` — a proper list, a dotted list or a single identifier, exactly as `lambda` accepts — and evaluates the body with those bindings. |

## Notes

* `(receive all expression body ...)` binds the whole list of values to `all`.
* `(receive () expression body ...)` accepts no values at all.
* The number of values must match the formals, as with any procedure call.

## Example

```scheme
(receive (q r) (floor/ 7 2) (list q r))         ; => (3 1)
(receive (a . rest) (values 1 2 3) (list a rest)) ; => (1 (2 3))
(receive all (values 1 2 3) all)                 ; => (1 2 3)
```
