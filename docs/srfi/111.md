# (srfi 111) — boxes

One mutable cell, distinct from every other box.  A box is a first-class
object, so it can be stored in a list, passed to a procedure and captured by a
closure; it is not a pair, a vector or a record.

```scheme
(import (scheme base) (srfi 111))
```

## Procedures

| Procedure | Arguments | Description |
|---|---|---|
| `box` | `(box value)` | A fresh box holding `value`. |
| `unbox` | `(unbox box)` | The value inside; a non-box is an error. |
| `set-box!` | `(set-box! box value)` | Stores a new value and returns an unspecified value. |
| `box?` | `(box? object)` | `#t` for a box, `#f` for anything else. |

## Notes

* Two boxes holding `equal?` values are still different boxes: `(eq? (box 1)
  (box 1))` is `#f`, and so is `(equal? (box 1) (box 1))`.
* A box is written `#<box value>`.
* Boxes are ordinary Scheme data: sharing one between interpreter threads is a
  data race like any other (`(goscheme sync)` has the tools for that).

## Example

```scheme
(box? (box 1))                    ; => #t
(box? 1)                          ; => #f
(unbox (box 'v))                  ; => v
(let ((b (box 1)))
  (set-box! b (+ (unbox b) 41))
  (unbox b))                      ; => 42
(box (box 1))                     ; => #<box #<box 1>>
```
