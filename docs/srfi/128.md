# (srfi 128) — comparators

A comparator bundles the four operations a container needs — a type test, an
equality, an ordering and a hash function — so that a hash table, a set or a
sorting procedure can be handed one object instead of a pile of procedures.
The implementation is in Go; `hash-bound` and `hash-salt` are ordinary R7RS
parameters, so `parameterize` works on them.

```scheme
(import (scheme base) (srfi 128))
```

## The object

| Procedure | Arguments | Description |
|---|---|---|
| `make-comparator` | `(make-comparator type-test equality ordering hash)` | Builds a comparator from four parts.  Each part is a procedure or `#f`, and `#f` means "not provided": no type test accepts anything, no equality means `eqv?`, no ordering makes the comparator unordered, and no hash makes it unhashable.  A part that is neither a procedure nor `#f` is an error. |
| `comparator?` | `(comparator? object)` | `#t` for a comparator. |
| `comparator-ordered?` | `(comparator-ordered? comparator)` | `#t` when it has an ordering. |
| `comparator-hashable?` | `(comparator-hashable? comparator)` | `#t` when it has a hash function. |
| `comparator-type-test-predicate` | `(comparator-type-test-predicate comparator)` | The type test, or `#f`. |
| `comparator-equality-predicate` | `(comparator-equality-predicate comparator)` | The equality procedure, or `#f` when it is the `eqv?` default. |
| `comparator-ordering-predicate` | `(comparator-ordering-predicate comparator)` | The ordering procedure, or `#f`. |
| `comparator-hash-function` | `(comparator-hash-function comparator)` | The hash function, or `#f`. |
| `comparator-test-type` | `(comparator-test-type comparator object)` | Applies the type test; `#t` when there is none. |
| `comparator-check-type` | `(comparator-check-type comparator object)` | `#t`, or an error naming the value when the type test rejects it. |

## The operations

| Procedure | Arguments | Description |
|---|---|---|
| `=?` | `(=? comparator value ...)` | `#t` when every neighbouring pair is equal; a single value is trivially `#t`. |
| `<?` | `(<? comparator value ...)` | The same for the ordering; a comparator without one is an error. |
| `>?` | `(>? comparator value ...)` | The ordering reversed. |
| `<=?` | `(<=? comparator value ...)` | Less or equal, pair by pair. |
| `>=?` | `(>=? comparator value ...)` | Greater or equal. |
| `comparator-if<=>` | `(comparator-if<=> comparator a b less equal greater)` | Compares `a` and `b` and picks a branch: the equality branch when they are equal, the ordering branch when `a < b`, the other one otherwise.  A branch that is a procedure is called with no arguments; anything else is returned as it stands. |

## Ready-made comparators

| Procedure | Arguments | Description |
|---|---|---|
| `make-eq-comparator` | `(make-eq-comparator)` | Equality `eq?`, `default-hash`, no ordering. |
| `make-eqv-comparator` | `(make-eqv-comparator)` | Equality `eqv?`. |
| `make-equal-comparator` | `(make-equal-comparator)` | Equality `equal?`. |
| `make-default-comparator` | `(make-default-comparator)` | Equality `equal?`, `default-hash`, and an ordering that handles the atoms: numbers numerically, strings, characters and symbols by their text, and `#f` before `#t`.  Asking it to compare a pair with a number raises rather than inventing an answer. |

## Hashing

Every hash function returns an exact integer in `[0, (hash-bound))`, shifted by
`(hash-salt)`, and raises when given the wrong type.  The case-insensitive ones
fold case first, so values that are `string-ci=?` or `char-ci=?` hash alike.

| Procedure | Arguments | Description |
|---|---|---|
| `hash-bound` | `(hash-bound)` | A parameter: the exclusive upper bound of every hash result (default 1000000007). |
| `hash-salt` | `(hash-salt)` | A parameter: an integer mixed into every hash (default 0). |
| `default-hash` | `(default-hash object)` | Hashes any value; values that are `equal?` hash the same way. |
| `boolean-hash` | `(boolean-hash boolean)` | For `#t` and `#f`. |
| `char-hash` | `(char-hash char)` | For a character. |
| `char-ci-hash` | `(char-ci-hash char)` | Case-insensitive. |
| `string-hash` | `(string-hash string)` | For a string. |
| `string-ci-hash` | `(string-ci-hash string)` | Case-insensitive. |
| `symbol-hash` | `(symbol-hash symbol)` | For a symbol. |
| `number-hash` | `(number-hash number)` | For any number, exact or inexact. |

## Notes

* A missing operation is an error when it is *used*, never a wrong answer: an
  unordered comparator raises from `<?`, `>?`, `<=?` and `>=?`.
* The hash values are an implementation detail — a program may rely on equal
  values hashing alike and on the bound, not on particular numbers.
* The standard's recursive constructors (`make-pair-comparator`,
  `make-list-comparator`, `make-vector-comparator`) are **not provided yet**.

## Example

```scheme
(import (scheme base) (scheme write) (srfi 128))

(define numbers (make-comparator number? = < number-hash))
(comparator? numbers)                        ; => #t
(comparator-ordered? numbers)                ; => #t
(=? numbers 1 1 1)                           ; => #t
(<? numbers 1 2 3)                           ; => #t
(comparator-if<=> numbers 3 2 'less 'equal 'greater)   ; => greater
(comparator-check-type numbers 5)            ; => #t

(define default (make-default-comparator))
(<? default "a" "b")                         ; => #t
(<? default #f #t)                           ; => #t
(parameterize ((hash-bound 10)) (< (default-hash "x") 10))   ; => #t
(= (string-ci-hash "ABC") (string-ci-hash "abc"))            ; => #t
```
