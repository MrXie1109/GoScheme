# (srfi 2) — `and-let*`

An `and` whose clauses can bind: each claw is evaluated in turn, the first one
that is false ends the whole form with `#f`, and the body runs with the
bindings made so far.  It is written in Scheme and embedded in the binary, so
it works in an executable produced by `goscheme pack`.

```scheme
(import (scheme base) (srfi 2))
```

## Syntax

| Form | Arguments | Description |
|---|---|---|
| `and-let*` | `(and-let* (claw ...) body ...)` | Each claw is a list, and every claw is tested: |

The three claw shapes are:

* `(variable expression)` — evaluates `expression`, binds it to `variable` for
  the rest of the form, and fails when the value is false;
* `(expression)` — evaluates and tests it without binding anything;
* `variable` — tests the variable's current value, for a claw that was bound
  by an enclosing form.

With no body the value of the last claw is the value of the whole form; with no
claws at all it is `#t`.

## Notes

* A failing claw stops the claws after it, so their side effects do not happen.
* The bindings are visible to later claws and to the body.
* `(and-let* ())` is `#t`, and `(and-let* () body ...)` is `(begin body ...)`.

## Example

```scheme
(and-let* ((x 2) ((even? x)) (y (* x 10))) y)   ; => 20
(and-let* ((x 1) ((even? x))) 'yes)             ; => #f
(and-let* ((entry (assv 'b '((a . 1) (b . 2))))) (cdr entry))  ; => 2
(let ((x 5)) (and-let* (x (> x 3)) 'big))       ; => big
```
