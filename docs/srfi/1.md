# (srfi 1) — the list library

The complete SRFI-1 API: constructors, predicates, selectors, folds and
unfolds, filtering, searching, deleting, association lists and the `lset-` set
operations.  It is implemented in Go, so a builtin predicate or comparison
(`<`, `even?`, `equal?`, ...) is applied inside the loop rather than through a
call per element.

```scheme
(import (scheme base) (srfi 1))
```

**The fold argument order is SRFI-1's**, which is *not* the one R6RS and
`(goscheme fast)` use: `fold` calls `(kons element accumulator)`, and
`fold-right` does too.  `(goscheme fast)`'s `fold-left` calls
`(proc accumulator element)`.  Watch that when porting.

## Constructors

| Procedure | Arguments | Description |
|---|---|---|
| `xcons` | `(xcons d a)` | `(cons a d)`: the flipped cons that makes a folder out of a cons. |
| `cons*` | `(cons* x ... tail)` | `(cons x1 (cons x2 ... tail))`; with one argument it is that argument. |
| `make-list` | `(make-list count [fill])` | A list of `count` elements, all `fill` (unspecified when omitted; it is R7RS's procedure). |
| `list-tabulate` | `(list-tabulate count proc)` | A list of `(proc i)` for `i` below `count`. |
| `list-copy` | `(list-copy list)` | A copy of the spine (R7RS's procedure). |
| `circular-list` | `(circular-list x ...)` | A list whose last pair points back at the first, so it has no end. |
| `iota` | `(iota count [start [step]])` | `count` numbers from `start` (0), adding `step` (1); the same binding `(goscheme fast)` exports. |

## Predicates

| Procedure | Arguments | Description |
|---|---|---|
| `proper-list?` | `(proper-list? x)` | `#t` for a finite list ending in `()`. |
| `circular-list?` | `(circular-list? x)` | `#t` for a chain of pairs that loops; answered with Brent's cycle detection, so it terminates. |
| `dotted-list?` | `(dotted-list? x)` | `#t` for a chain of pairs that ends in something other than `()`. |
| `not-pair?` | `(not-pair? x)` | `#t` for anything that is not a pair. |
| `null-list?` | `(null-list? x)` | `#t` for `()`, `#f` for a pair, and an error for anything that is not a list. |
| `list=` | `(list= elt= list ...)` | `#t` when all the lists have the same length and are element-wise `elt=`; different lengths are `#f`, not an error. |
| `length+` | `(length+ list)` | The length, or `#f` for a circular list; a non-list is an error. |

## Selectors

| Procedure | Arguments | Description |
|---|---|---|
| `first`, `second`, `third`, `fourth`, `fifth`, `sixth`, `seventh`, `eighth`, `ninth`, `tenth` | `(first list)` | The nth element, counting from 1; a list that is too short is an error. |
| `car+cdr` | `(car+cdr pair)` | Returns two values: the car and the cdr. |
| `last` | `(last list)` | The final element of a non-empty list. |
| `last-pair` | `(last-pair list)` | The final pair; a circular list is an error rather than a hang. |
| `take` | `(take n list)` | The first `n` elements; too short is an error. |
| `drop` | `(drop n list)` | Everything but the first `n` elements. |
| `take-right` | `(take-right n list)` | The last `n` elements, in order. |
| `drop-right` | `(drop-right n list)` | Everything but the last `n` elements. |
| `take!` | `(take! n list)` | The linear-update `take`; here it is the pure one. |
| `drop-right!` | `(drop-right! n list)` | The linear-update `drop-right`; pure here. |
| `split-at` | `(split-at n list)` | Returns two values, `(take n list)` and `(drop n list)`. |
| `split-at!` | `(split-at! n list)` | The linear-update `split-at`; pure here. |

## Miscellaneous

| Procedure | Arguments | Description |
|---|---|---|
| `concatenate` | `(concatenate list-of-lists)` | Appends them all, sharing the last. |
| `concatenate!` | `(concatenate! list-of-lists)` | The linear-update `concatenate`; pure here. |
| `append!` | `(append! list ...)` | Splices the lists by mutating the last pair of each but the last, which is shared. |
| `reverse!` | `(reverse! list)` | Reverses the pairs themselves and returns the new head; a circular list is an error. |
| `append-reverse` | `(append-reverse reversed tail)` | `(append (reverse reversed) tail)`. |
| `append-reverse!` | `(append-reverse! reversed tail)` | The linear-update form; pure here. |
| `zip` | `(zip list ...)` | A list of the rows of several lists, stopping at the shortest (SRFI-1 makes a length mismatch an error; this shares `(goscheme fast)`'s procedure). |
| `unzip1` | `(unzip1 list)` | The list of the cars of the tuples. |
| `unzip2` | `(unzip2 list)` | Returns two values: the list of first elements and the list of second elements. |
| `unzip3` | `(unzip3 list)` | Three values, from tuples of at least three elements. |
| `unzip4` | `(unzip4 list)` | Four values. |
| `unzip5` | `(unzip5 list)` | Five values. |
| `count` | `(count pred list ...)` | How many positions satisfy the predicate, applied to the elements of that position in one call.  It is exported from `(goscheme fast)` too, and also accepts a single vector there. |

## Folds, unfolds and mapping

| Procedure | Arguments | Description |
|---|---|---|
| `fold` | `(fold kons knil list ...)` | Left to right, calling `(kons element accumulator)`.  A builtin `+`, `-`, `*`, `/`, `max` or `min` stays in Go. |
| `fold-right` | `(fold-right kons knil list ...)` | Right to left, also `(kons element accumulator)`; the same binding `(goscheme fast)` exports. |
| `pair-fold` | `(pair-fold kons knil list ...)` | Like `fold`, but `kons` is given the successive **pairs**. |
| `pair-fold-right` | `(pair-fold-right kons knil list ...)` | The same from the right. |
| `reduce` | `(reduce kons ridentity list)` | A fold that seeds itself with the first element, so an empty list yields `ridentity`. |
| `reduce-right` | `(reduce-right kons ridentity list)` | The right-associative `reduce`, seeded with the last element. |
| `unfold` | `(unfold stop? mapper successor seed [tail-gen])` | Conses `(mapper seed)` while `(stop? seed)` is false, stepping with `successor`; the tail is `(tail-gen seed)` or `()`. |
| `unfold-right` | `(unfold-right stop? mapper successor seed [tail])` | The same, building the list from the right so `tail` ends up last. |
| `append-map` | `(append-map proc list ...)` | `(apply append (map proc list ...))`, concatenating in one pass. |
| `append-map!` | `(append-map! proc list ...)` | The linear-update form; pure here. |
| `map` | `(map proc list ...)` | R7RS's, exported from this library as the same binding. |
| `map!` | `(map! proc list ...)` | The linear-update `map`; pure here. |
| `map-in-order` | `(map-in-order proc list ...)` | The same as `map`, kept for SRFI-1 compatibility. |
| `for-each` | `(for-each proc list ...)` | R7RS's. |
| `pair-for-each` | `(pair-for-each proc list ...)` | Calls `proc` on the successive pairs, for their side effects. |
| `filter-map` | `(filter-map proc list ...)` | Maps and keeps the results that are not `#f`. |

## Filtering

| Procedure | Arguments | Description |
|---|---|---|
| `filter` | `(filter pred list)` | The elements the predicate accepts; `(goscheme fast)`'s binding, so a builtin predicate stays in Go. |
| `partition` | `(partition pred list)` | Returns two values: the accepted elements and the rest, each in order. |
| `remove` | `(remove pred list)` | The elements the predicate rejects. |
| `filter!` | `(filter! pred list)` | The linear-update `filter`; pure here. |
| `partition!` | `(partition! pred list)` | The linear-update `partition`; pure here. |
| `remove!` | `(remove! pred list)` | The linear-update `remove`; pure here. |

## Searching

| Procedure | Arguments | Description |
|---|---|---|
| `find` | `(find pred list)` | The first element the predicate accepts, or `#f`. |
| `find-tail` | `(find-tail pred list)` | The first pair whose car the predicate accepts, or `#f`. |
| `any` | `(any pred list ...)` | The first true value the predicate returns, or `#f`.  SRFI-1 semantics, shared with `(goscheme fast)`, which also accepts one vector. |
| `every` | `(every pred list ...)` | The last value the predicate returned when every position passes, or `#f`; `#t` for empty lists. |
| `list-index` | `(list-index pred list ...)` | The index of the first position that passes, or `#f`; shared with `(goscheme fast)`. |
| `take-while` | `(take-while pred list)` | The longest initial run that passes. |
| `drop-while` | `(drop-while pred list)` | What is left after that run. |
| `take-while!` | `(take-while! pred list)` | The linear-update form; pure here. |
| `span` | `(span pred list)` | Returns two values: that run and the rest. |
| `break` | `(break pred list)` | Like `span`, but the run ends at the first element that **passes**. |
| `span!` | `(span! pred list)` | The linear-update `span`; pure here. |
| `break!` | `(break! pred list)` | The linear-update `break`; pure here. |

## Deleting

| Procedure | Arguments | Description |
|---|---|---|
| `delete` | `(delete x list [equal?])` | The list without the elements equal to `x`; the comparison defaults to `equal?`. |
| `delete-duplicates` | `(delete-duplicates list [equal?])` | Keeps the first of each group of equal elements, in order. |
| `delete!` | `(delete! x list [equal?])` | The linear-update `delete`; pure here. |
| `delete-duplicates!` | `(delete-duplicates! list [equal?])` | The linear-update form; pure here. |

## Association lists

| Procedure | Arguments | Description |
|---|---|---|
| `assoc` | `(assoc key alist [equal?])` | The first pair whose car matches, or `#f`; R7RS's procedure, which already takes the optional comparison. |
| `member` | `(member x list [equal?])` | The first sublist whose car matches, or `#f`; R7RS's. |
| `alist-copy` | `(alist-copy alist)` | A copy of the spine in which every pair is fresh; the keys and values are shared. |

## Set operations

These compare with `elt=`, take one or more lists, and preserve the order of
their inputs; SRFI-1 leaves the order unspecified, so this is a refinement
rather than a requirement.  Duplicates inside the first list are kept where
that list is filtered (`lset-intersection`, `lset-difference`).

| Procedure | Arguments | Description |
|---|---|---|
| `lset<=` | `(lset<= elt= list ...)` | `#t` when every list is a subset of the one before it. |
| `lset=` | `(lset= elt= list ...)` | `#t` when every pair of neighbours is mutually a subset. |
| `lset-adjoin` | `(lset-adjoin elt= list elt ...)` | The list with the `elt`s that are not already in it appended. |
| `lset-union` | `(lset-union elt= list ...)` | The union, first-seen order, no duplicates. |
| `lset-intersection` | `(lset-intersection elt= list ...)` | The elements of the first list that appear in all the others. |
| `lset-difference` | `(lset-difference elt= list ...)` | The elements of the first list that appear in none of the others. |
| `lset-xor` | `(lset-xor elt= list ...)` | The symmetric difference, folded left to right. |
| `lset-diff+intersection` | `(lset-diff+intersection elt= list ...)` | Returns two values: the difference and the intersection. |

## Notes

* **Shared bindings.**  `iota`, `take`, `drop`, `take-right`, `drop-right`,
  `split-at`, `last`, `filter`, `partition`, `find`, `delete`,
  `delete-duplicates`, `zip`, `count`, `list-index`, `any` and `every` are the
  same bindings `(goscheme fast)` exports, and `map`, `for-each`, `member`,
  `assoc`, `make-list` and `list-copy` are R7RS's.  Importing both libraries
  therefore cannot make them disagree.
* **Lists must be proper** unless the description says otherwise; an improper
  list raises rather than walking off the end, and the procedures that would
  loop forever on a circular list (`last-pair`, `reverse!`, `length+`) detect
  it.
* **Equal lengths.**  The folds, maps and `count`/`list-index` with several
  lists require the lists to have the same length and raise otherwise; `list=`
  and `zip` do not (they answer `#f` and stop at the shortest).
* **The linear-update procedures are pure here**, as SRFI-1 permits, except
  `reverse!` and `append!`, which really do reuse the pairs.

## Example

```scheme
(import (scheme base) (scheme write) (srfi 1))

(fold - 0 '(1 2 3))                          ; => 2
(fold cons '() '(1 2 3))                     ; => (3 2 1)
(reduce-right - 0 '(1 2 3))                  ; => 2
(unfold (lambda (x) (> x 3)) (lambda (x) (* x x)) (lambda (x) (+ x 1)) 1)
                                             ; => (1 4 9)
(filter-map (lambda (x) (and (even? x) (* x 10))) '(1 2 3 4))
                                             ; => (20 40)
(take-while (lambda (x) (< x 3)) '(1 2 3 4)) ; => (1 2)
(delete-duplicates '(1 2 1 3 2))             ; => (1 2 3)
(lset-union string=? '("a" "b") '("b" "c"))  ; => ("a" "b" "c")
(any (lambda (x) (and (even? x) x)) '(1 3 4)) ; => 4
```
